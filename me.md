### 6.2 AI Engineering (building AI systems, not just using AI)

#### Multi-agent architecture (Mandate)

- **Architettura multi-agent**: evaluator + researcher + manager + executor — ognuno con scope distinto e responsabilità ben definita
- **Memoria a lungo termine** per agent autonomi: ricordano stato, decisioni passate, contesto cross-cycle

- **Multi-provider abstraction**: DeepInfra (Gemma per cost efficiency), OpenRouter (alternative), Anthropic Claude (premium)

- **Subscription/credit engine** per-agent (USD-denominated) con dual-pool accounting (master + bonus)
- **Cost-proportional metering**: `trigger_unit_cost_usd` + markup PAYG fallback
- **Billing per token/model usage** con tracking attribuibile a singolo agent

#### MCP (Model Context Protocol) gateway

- **mcp-gateway**: componente dedicato che fa da interfaccia tra LLM e blockchain tools
- Espone tool blockchain (read state, simulate transactions, fetch market data) come MCP server
- Separation of concerns: agent ragiona, MCP esegue letture, signing-service esegue scritture

#### Agent testing infrastructure

- **agent-tester**: componente dedicato per testare agent AI prima del deploy
- Quality assurance per output non-deterministici (LLM)
- Validation di policy compliance (l'agent rispetta i bound della risk × strategy matrix?)
- Performance tracking + regression detection

#### LLM-based document parsing

- Parsing LLM di **PDF / Excel / CSV** per data ingestion (file picking pharma, dati farmaceutici/logistici)
- Schema validation post-LLM-extraction (zod, type guards)

#### Prompt engineering production-grade

- Brief self-contained che sopravvivono a context isolation
- Safety patterns (refuse + clarify quando non c'è conviction)
- Output structured (JSON, function calling, schema-validated)
- Multi-turn reasoning con state persistence
